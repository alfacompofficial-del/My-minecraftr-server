## 🎯 Возможности

- 🔐 **Авторизация** — игрок зависает на Y=255 до входа
- 🏠 **Привате** — деревянный топор, 1 регион на игрока
- 💰 **Экономика** — стартовые 500$, торговля через /ah
- 🎁 `/kit start` — стартовый набор для новичков
- 🛒 `/ah` — аукционный дом (покупка/продажа)
- 🪟 **Скорборд** — ник, статус, время, баланс
- 📋 **Таблист** — Tab показывает ник + роль игрока

## 🚀 Деплой на Minestrator

### Способ 1 — через скрипт
```bash
# Запусти deploy.sh на сервере (через SSH или консоль)
bash deploy.sh
```

### Способ 2 — вручную
1. Скачай плагины вручную (ссылки в `ИНСТРУКЦИЯ.txt`)
2. Загрузи через файловый менеджер Minestrator
3. Скопируй `server.properties` и конфиги плагинов

---

## 📋 Быстрая настройка после деплоя

```bash
# В консоли Minestrator:
lp creategroup user
lp creategroup admin
lp group admin permission set * true
lp group default parent set user
lp user Bilol29146192 parent set admin
```
